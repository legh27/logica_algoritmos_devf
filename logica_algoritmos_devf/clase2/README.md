# Lista de Compras

Solución para el ejercicio de gestión de una lista de compras.

## Archivos

- `listaCompras.js`: contiene el arreglo `listaDeCompras` y las funciones:
  - `agregarProducto(producto)`
  - `eliminarProducto(producto)`
  - `mostrarLista()`
- `app.js`: ejemplo de uso de las funciones con mensajes en consola.

## Uso

Desde la carpeta `clase2`, ejecutar:

```bash
node app.js
```

## Reglas implementadas

- Se evita agregar productos duplicados.
- Se valida que el nombre del producto no esté vacío.
- Se muestra la lista completa de compras en consola.
